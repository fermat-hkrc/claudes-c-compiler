Issue Synopsis

Function-local enum constant permanently clobbers the global one (undo-log has no enums_shadowed restore)

Expected behaviorenum_constants["F"] == 1 (global E restored after f's scope pops)
Observed behaviorenum_constants["F"] == 2 (inner value leaked)
Impact assessmentSilent wrong compile-time constants: after any function with a local `enum { E = ... }`, the global E keeps the inner value for the rest of the TU.
Minimal counterexampleg=1, l=2 — `enum { E = 1 }; void f(void) { enum { E = 2 }; } enum { F = E + 0 };` gives F == 2 (inner value leaked past scope exit)

Documentation: The cited documentation states this behavior IS handled; the code violates the document it ships with.
