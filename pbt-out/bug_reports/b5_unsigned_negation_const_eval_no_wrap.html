Issue Synopsis

SemaConstEval unary minus on unsigned constants does not wrap modulo 2^width

Expected behaviorconst_values[p] == 1 (-(4294967295u) wraps to 1u; C11 6.5.3.3p4, gcc 9.4 agrees)
Observed behaviorconst_values[p] == -4294967295
Impact assessmentEnum values, array sizes, and static initializers built from negated unsigned constant expressions get a negative value instead of the wrapped unsigned one (e.g. -4294967295 instead of 1).
Minimal counterexamplee = Un("-", Bin("+", Cast("unsigned", Lit(0)), Lit(-1))) — `int p = -((unsigned)(0) + (-1));` const-folds to -4294967295; C (gcc 9.4) wraps to 1
