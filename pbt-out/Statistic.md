# Statistic — FMBot-PBT 問題統計（全追蹤器口徑，雙源驗證）

**FMBot-PBT 發現了 2011 個功能類邏輯問題**（GitHub 追蹤器當前全部 open issue）。其中 **3 張經 509 張全量人工復核（explore/pbt-test 分支 `pbt-out/sampling`，user-confirmed）判定為假陽性並予剔除**（#30/#119/#247：BICS/EON/ORN 立即數別名——僅 llvm-mc 支持的語法增強請求，非缺陷）。**統計母體 = 2008 個有效缺陷。** 已關閉之 17 張為操作失誤（重複歸檔／傘單拆分／已修復），一律不計、亦不視為假陽性。

分類方法（雙源融合）：① 前 509 張直接採用 explore 分支逐一人工驗證之 verdict 分類；② 其餘 1499 張按修正後關鍵詞規則歸類（詞邊界修正：`nop≠noprefix` 等）＋人工校準。分佈偏斜為**驗證過的事實**（復核結論：首 509 張中 90% 屬「非法輸入被靜默接受並編碼」），非分類誤差。

**方法說明**：母體 = API 抓取之全部 open issue（2011）− 3 張人工復核假陽性 = 2008。分類採雙源：前 509 張用 explore/pbt-test 人工驗證表（verdict_class 映射：silent-accept/warn-accepts/warning-class-CU→診斷；differential/reverse→運算錯誤；panic-on-invalid/parser-masked→編譯器崩潰；C-level 按 S1/S2 分派）；其餘按修正關鍵詞規則（含詞邊界修正）＋人工校準。CWE 為類級映射。Severity 依 issue 正文標註＋「靜默錯值＝高、可致錯行為＝中、純缺失＝低」校準。
