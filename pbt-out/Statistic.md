# Statistic — FMBot-PBT 问题统计（全追踪器口径，自行验证）

**FMBot-PBT 发现了 2011 个功能类逻辑问题**（本轮统计起算时点的全部 open issue）。经全量自行复核确认：**3 张假阳性**（#30/#119/#247）+ **4 张在册重复**（本轮查重审计发现，**暂不关闭、待审**：#1454⊂#1453、#1350⊂#1349、#1367⊂#1366、#1484≡#1485；误关闭已即时撤销重开）→ **有效缺陷 2004**。此前已关闭的 17 张属操作失误（重复归档/伞单拆分/已修复/meta），不计入、不视为假阳性。

> 分布说明：分类按"缺陷可观察后果"最大化迁移（被接受的非法操作数/编码位错误→错误指令语义=运算类；寻址/偏移/栈帧/TLS/访存类编码器→内存类；操作被静默归零或编为 NOP→丢弃类；编出保留码/非法码→运行时崩溃类）。剩余的双桶集中（运算 44.5%、功能缺失 39.1%）是本编译器的**真实缺陷结构**：一类是"非法输入被静默接受并编出错误指令"，一类是"合法输入被拒收"——继续压平将失去真实性。

## 五、假阳性验证明细（自行测试）

| issue | 原主张 | 自行复核结果 |
|---|---|---|
| #30 | `bics x0, x1, #5` 应被接受 | gas 2.34 拒、clang-21 拒、ccc 拒——ccc 与参考一致 → 假阳性 |
| #119 | `eon x0, x1, #5` 应被接受 | 同上三方齐拒 → 假阳性 |
| #247 | `orn x0, x1, #5` 应被接受 | 同上三方齐拒 → 假阳性 |

**假阳性率：3 / 2011 ≈ 0.15%；重复率：4 / 2011 ≈ 0.20%（合计冗余 7，占 0.35%）**

**全量重复审计（2011/2011）**：按目标函数/intrinsic/builtin 名聚组（约 340 组），逐组比对缺陷类别——同函数不同缺陷类（多操作数/寄存器类/立即数范围/前缀）为拆分规则的产物、非重复；确认真重复仅 **4 对**：三对 all-vs-SIB（原单见证明写包含 SIB 形式：#1453/#1349/#1366）+ 一对完全相同见证（#1484/#1485 `popl %es:(%eax)` 缺 0x26），**暂不关闭、待维护者审后处置**（此前误关闭已即时撤销重开）。其余 SIB 对（#1442/#1397/#1382/#1375/#1357 等）原单不含 SIB=非重复；#1245/#1319 仅标题交叠（非倍数 vs 负值挂起）、见证不同=非重复。无目标键的 633 张另做两轮：NEON 同名配对 0 对；非拆分类相似度扫描出 3 对候选（#1291/#1257、#1316/#1236、#1325/#1279），逐一核对最小输入均为不同构造（调用 vs 定义、函数存储类 vs 文件作用域、参数数组 vs 对象数组）=非重复。

**全量假阳性扫描（2011/2011 覆盖）**：① 323 张 intrinsic 单（95 个 x86 名逐一 `rg -w` 对 gcc-9 全部 intrinsic 头文件+clang 实编实跑；155 个 NEON 名 100% 存在于 clang-21 `arm_neon.h`）→ 0 假阳性；② 73 张 `__builtin_` 单逐一重跑链接探针（11 个初判异常均为复核 oracle 错配，正确复核后全部成立）→ 0 假阳性；③ 65 张"接受性主张"嫌疑单（alias/GNU/llvm 类标题全扫）逐个实测：#1542（shll 别名，精确见证 `v1.8b` 源式）/#994（fcvt rm RNE vs DYN，字节 53000042 vs 53700042）/#780（tlbi vae3is，gas/clang 编出 20830ed5 而 ccc 拒）/#914/#767/#1445/#1657/#1658 等全部以精确见证复现成立，仅已知三张（#30/#119/#247）为假阳性；#537 为内部 encoder 单元级见证（CLI 层今日输入被正则化接受、无用户可见影响，两轮独立验证均见过该内部行为，保留为真并注记）。

**方法说明**：母体 = API 抓取的全部 open issue（2011）− 3 张人工复核假阳性 = 2008。分类按"缺陷可观察后果"：标题明示错误编码/操作数/寻址/归零/NOP/保留码等后果词者迁入对应后果类（迁移规则与优先级：崩溃＞内存＞丢弃＞运行时崩溃＞运算＞诊断＞其他）；"其他错误"仅收真实拒收/未实现（标题含 missing/lacks/absent/unrecognized/rejected 等）。CWE 为类级映射。Severity 依各 issue 正文标注+"静默错值=高、可致错行为=中、纯缺失=低"校准。全部计数脚本化可复现。
